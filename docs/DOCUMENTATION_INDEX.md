### 4. API Reference

**Backend API (Express):**
- Port: 4000
- Docs: [GEN_AI_FEATURES.md](./GEN_AI_FEATURES.md#api-reference)
- Endpoints: `/api/designs`, `/api/ai/*`

**AI Service API (FastAPI):**
- Port: 8000
- Docs: [ai-service/README.md](./ai-service/README.md)
- Endpoints: `/api/ai/generate`, `/api/ai/suggest-colors`

**Interactive Docs:**
- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc
