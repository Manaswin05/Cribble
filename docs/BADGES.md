## Custom Badges

### Create Your Own

Use [Shields.io](https://shields.io/) to create custom badges:

```
https://img.shields.io/badge/<LABEL>-<MESSAGE>-<COLOR>?style=<STYLE>&logo=<LOGO>
```

**Examples:**

```markdown
![Custom](https://img.shields.io/badge/Cribble-v1.0.0-blueviolet?style=for-the-badge)
![Custom](https://img.shields.io/badge/AI-Powered-ff69b4?style=for-the-badge&logo=openai)
![Custom](https://img.shields.io/badge/Made%20with-❤️-red?style=for-the-badge)
```

## Badge Styles

### Available Styles

- `flat` - Default flat style
- `flat-square` - Flat with square edges
- `for-the-badge` - Large badge
- `plastic` - Plastic style
- `social` - Social media style

**Example:**
```markdown
![Flat](https://img.shields.io/badge/Style-Flat-blue?style=flat)
![Flat Square](https://img.shields.io/badge/Style-Flat%20Square-blue?style=flat-square)

```
