# ⌨️ Cribble Keyboard Shortcuts

## Editing

| Shortcut | Action | Description |
|----------|--------|-------------|
| `Ctrl+Z` / `Cmd+Z` | Undo | Undo last action |
| `Ctrl+Shift+Z` / `Cmd+Shift+Z` | Redo | Redo undone action |
| `Ctrl+Y` / `Cmd+Y` | Redo | Alternative redo shortcut |
| `Ctrl+C` / `Cmd+C` | Copy | Copy selected element |
| `Ctrl+V` / `Cmd+V` | Paste | Paste copied element |
| `Ctrl+D` / `Cmd+D` | Duplicate | Duplicate selected element |
| `Delete` or `Backspace` | Delete | Delete selected element |
| `Escape` | Deselect | Clear selection / Close menus |

## View

| Shortcut | Action | Description |
|----------|--------|-------------|
| `Ctrl++` / `Cmd++` | Zoom In | Increase canvas zoom |
| `Ctrl+-` / `Cmd+-` | Zoom Out | Decrease canvas zoom |
| `Ctrl+0` / `Cmd+0` | Reset Zoom | Reset zoom to 100% |
| `?` | Show Shortcuts | Display shortcuts panel |

## File

| Shortcut | Action | Description |
|----------|--------|-------------|
| `Ctrl+S` / `Cmd+S` | Save | Export design as JSON |

## 🖱️ Context Menu (Right-Click)

### On Elements
- **Copy** - Copy the element
- **Duplicate** - Create a copy with offset
- **Delete** - Remove the element

### On Canvas Background
- **Paste** - Paste copied element
- **Add Square** - Insert new square
- **Add Circle** - Insert new circle
- **Add Text** - Insert new text element

## 💡 Tips

- All shortcuts work on both Windows (Ctrl) and Mac (Cmd)
- Press `?` anytime to see shortcuts in the app
- Right-click is your friend for quick actions
- `Escape` closes any open menu or dialog
- Shortcuts are disabled when editing text (press Escape first)

## 🎯 Common Workflows

### Quick Duplicate
1. Select element
2. Press `Ctrl+D`
3. Element duplicated with offset

### Copy to Multiple Places
1. Select element
2. Press `Ctrl+C`
3. Press `Ctrl+V` multiple times

### Rapid Prototyping
1. Add elements with toolbar
2. Drag to position
3. `Ctrl+D` to duplicate
4. Adjust and repeat
5. `Ctrl+S` to save

### Undo Mistakes
1. Made a mistake? `Ctrl+Z`
2. Changed your mind? `Ctrl+Shift+Z`
3. Navigate your entire history!

## 🚀 Power User Tips

- **Ctrl+D is faster than Ctrl+C then Ctrl+V**
- **Use Ctrl+0 to quickly reset zoom**
- **Right-click for context-aware actions**
- **Press ? if you forget a shortcut**
- **Escape is your panic button**
