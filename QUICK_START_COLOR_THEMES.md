# 🚀 Quick Start: Color Theme Recommender

## Try It Now!

1. **Start the app**
   ```bash
   npm run dev
   ```

2. **Navigate to Studio**
   - Click on "Studio" in the sidebar
   - Or go directly to the Studio tab

3. **Open the AI Chat**
   - Look for the chat panel on the right side
   - You'll see the AI assistant greeting

4. **Request a Color Theme**
   
   Type any of these commands:
   
   ```
   "suggest color theme for luxury brand"
   "generate palette for tech startup"
   "color theme for healthcare"
   "recommend colors for food blog"
   "palette for minimalist website"
   ```

5. **Explore the Palette**
   - A beautiful modal will appear with your color palette
   - Click any color to copy its hex code
   - Toggle between Light and Dark modes
   - See a live preview of the colors in action

6. **Export Your Palette**
   - Choose your format: CSS, Tailwind, or JSON
   - Click "Download" to get the file
   - Use it directly in your project!

💡 **Use Keywords**: Words like "calm", "bold", "tech", "nature" help match themes

💡 **Try Variations**: If you don't like the first result, rephrase your request

💡 **Combine Concepts**: "modern tech startup with warm colors"
